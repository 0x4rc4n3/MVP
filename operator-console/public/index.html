Cryptographic Security Guarantees & Boundaries

Post-Quantum standard definitions and Zero Trust Architecture (ZTA) security boundaries of the ScatterID engine

01 Post-Quantum Standards

1. NIST ML-DSA-65 Digital Signatures

Implements NIST FIPS 204 post-quantum module-lattice-based digital signatures, offering Category 3 security (AES-192 equivalent) resistant to Shor's algorithm quantum attack vectors.

02 Threshold Cryptography

2. Shamir 3-of-5 Threshold Secret Sharing

Identity claims are split into 5 polynomial secret shares across independent database containers. Any 3 shares can reconstruct the proof, while 2 or fewer reveal zero mathematical information.

03 Zero-Trust KMS

3. Zero-Trust Vault KMS Storage

Post-quantum private keypairs are generated and stored exclusively inside HashiCorp Vault KV v2 engine. Keys are never exposed on disk or environment variables.

04 Consensus Ledger

4. Immutable Blockchain Ledger Anchoring

Credential IDs and SHA3-256 data hashes are immutably committed to Hyperledger Fabric via Raft consensus, establishing an unalterable audit ledger.
